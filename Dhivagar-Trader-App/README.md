# Dhivagar Trader

Trading journal and discipline tracker PWA.

## Included
- Dashboard: net P&L, trade count, win rate, habit streak
- Trade journal: XAUUSD, NIFTY 50, Forex, Crypto
- Daily habits and custom habits
- Manual economic calendar with best-effort 30-minute browser reminders
- JSON backup and restore
- Offline caching and Android home-screen install support

## Publish on GitHub Pages
1. Upload every file in this folder to the root of `Hacker-Dhiva/Dhivagar-Trader`.
2. GitHub repository → Settings → Pages.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for GitHub Pages to provide the site URL. Open it in Android Chrome.
5. Chrome menu → **Add to Home screen** / **Install app**.

## Limitations
Data stays in this browser on this device; export JSON backups regularly. The economic calendar is manual. Browser reminders are best-effort and not guaranteed while the app is fully closed. No broker integration, live news feed, or automatic market prices are included. This is a journal, not financial advice.
